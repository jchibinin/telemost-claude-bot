# Claude в чате Яндекс Мессенджера / Телемоста

Бот для Яндекс Мессенджера: читает групповой чат и отвечает в него через Claude, учитывая контекст переписки.
Чат можно использовать и во время видеозвонка в Телемосте, запущенного из этого чата.

```
чат Мессенджера ──getUpdates──▶ bot.py ──▶ Claude (API или Claude Code по подписке) ──sendText──▶ тот же чат
```

## Что нужно

- **Яндекс 360 для бизнеса**, тариф «Основной» или выше: боты (Bot API) есть только начиная с него.
  Бот общается только с сотрудниками организации.
- **Python 3.10+**.
- **Claude**, один из вариантов:
  - подписка Claude (Pro/Max) и Claude Code. Бот вызывает `claude -p`, это подходит для личного использования;
  - API-ключ Anthropic ([console.anthropic.com](https://console.anthropic.com)), оплата отдельно, по токенам.

## Установка

```bash
git clone https://github.com/jchibinin/telemost-claude-bot.git
cd telemost-claude-bot
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt     # Linux/macOS: .venv/bin/python
copy .env.example .env                                         # Linux/macOS: cp
```

### 1. Бот в Яндекс 360

В [admin.yandex.ru](https://admin.yandex.ru) администратор организации создаёт бота (раздел «Боты»).
Токен показывается один раз: впишите его в `.env` как `YANDEX_BOT_TOKEN`.

### 2. Доступ к Claude

**По подписке** (`BACKEND=cli`): получите долгоживущий токен. Команда интерактивная, откроется браузер:

```bash
claude setup-token
```

Затем впишите в `.env`:

```
BACKEND=cli
CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-...
```

Если `claude` нет в PATH, бот ищет `claude.exe` десктопного приложения Claude в `%APPDATA%\Claude\claude-code\`.
Можно указать путь явно: `CLAUDE_CLI=...`.

**По API** (`BACKEND=api`): впишите `ANTHROPIC_API_KEY=...`.

### 3. Чат

В чат встречи Телемоста бота добавить не получилось. Поэтому бот сам создаёт групповой чат организации,
где он администратор, и добавляет в него вас:

```bash
.venv\Scripts\python.exe create_chat.py --name "Созвоны с Клодом" ваш-логин
```

Логин нужен ровно в том виде, в каком его знает Мессенджер. Чтобы его узнать, запустите `bot.py --dump`
и напишите боту в личку: логин будет в поле `from.login`.

Видеозвонок запускайте из этого чата, тогда переписка во время звонка тоже пойдёт через бота.

## Запуск

```bash
.venv\Scripts\python.exe bot.py          # работа
.venv\Scripts\python.exe bot.py --dump   # только печатать входящие события (отладка)
```

## Как бот себя ведёт

- Отвечает на каждое сообщение. Если несколько сообщений пришло, пока Claude думает, ответ будет один на все сразу.
- В Claude уходят последние `BOT_HISTORY` сообщений чата (по умолчанию 100) вместе с прошлыми ответами бота.
  История хранится в `history.json` и переживает перезапуск.
- Команды в чате:
  - `/new` (или `/новый`) — забыть переписку и начать заново, сообщения в чате остаются;
  - `/clear` (или `/очистить`) — удалить из чата всё, что бот видел с прошлой очистки, и забыть переписку.
- Сообщения других ботов и свои собственные бот игнорирует.
- В режиме `cli` Claude Code запускается без инструментов (`--tools ""`): сообщения из чата не могут заставить
  его что-то выполнить на вашей машине.
- Claude пишет в разметке, которую понимает Мессенджер: `**жирный**`, `__курсив__`, `~~зачёркнутый~~`,
  `++подчёркнутый++`, `` `код` ``, ссылки и блоки кода. Заголовков, таблиц и цитат в Мессенджере нет.

## Настройки (`.env`)

| Переменная | По умолчанию | |
|---|---|---|
| `YANDEX_BOT_TOKEN` | — | токен бота из Яндекс 360 |
| `BACKEND` | `api` | `cli` — Claude Code по подписке, `api` — Anthropic API |
| `CLAUDE_CODE_OAUTH_TOKEN` | — | для `cli`, из `claude setup-token` |
| `ANTHROPIC_API_KEY` | — | для `api` |
| `CLAUDE_MODEL` | `claude-opus-5-5` | модель |
| `CLAUDE_EFFORT` | `low` | `low` / `medium` / `high`: выше точнее, но медленнее |
| `BOT_TRIGGERS` | пусто | слова через запятую; если заданы, бот отвечает в группах только на сообщения с ними |
| `BOT_HISTORY` | `100` | сколько последних сообщений видит Claude |
| `BOT_SYSTEM` | см. `bot.py` | свой системный промпт |
| `CLAUDE_CLI` | автопоиск | путь к `claude` / `claude.exe` |

`.env`, `history.json` (переписка) и `state.json` в репозиторий не попадают, см. `.gitignore`.
